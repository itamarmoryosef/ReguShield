# תבניות PDF רשמיות

User: Please drop your `fire-safety.pdf`, `accessibility.pdf` and the three
police files (`police-4-2a.pdf`, `police-4-2b.pdf`, `police-4-8.pdf`) into this folder.

מנוע יצירת הטפסים (`lib/pdf/generate-form.ts`) טוען את הקבצים מתיקייה זו וכותב את
פרטי העסק על גבי הטופס המקורי, במקום לייצר טופס חדש.

## קבצים נדרשים

| קובץ | טופס | מצב |
| --- | --- | --- |
| `fire-safety.pdf` | תצהיר בבקשה לרישיון עסק – אישור על יסוד תצהיר כבאות (3 עמודים, A4) | מותקן |
| `accessibility.pdf` | תצהיר על התקיימות הוראות הנגישות בעסק, לפי סעיף 8ב לחוק רישוי עסקים (2 עמודים, A4) | מותקן |
| `police-4-2a.pdf` | דרישות משטרה לפריט 4.2א - בית קפה / מסעדה (4 עמודים, A4) | מותקן |
| `police-4-2b.pdf` | דרישות משטרה לפריט 4.2ב - מזנון / בית אוכל אחר (4 עמודים, A4) | מותקן |
| `police-4-8.pdf` | דרישות משטרה לפריט 4.8 - משקאות משכרים (9 עמודים, A4) | מותקן |

בטפסי המשטרה ממולא נספח "נתונים כלליים של העסק" שבסוף המסמך (עמוד 4 בפריטי 4.2,
עמוד 9 בפריט 4.8). הטופס שנשלח נבחר לפי פריט הרישוי שבפרטי העסק, ולוגיקת החיוב
והפטור נמצאת ב-`lib/police.ts`.

אם קובץ חסר, יצירת הטופס נכשלת עם הודעה ברורה למשתמש:
"לא נמצא קובץ התבנית. יש להעלות את הטופס המקורי לנתיב public/templates/<שם הקובץ>".

## החלפת תבנית או כיוונון מיקומים

מיקומי השדות מוגדרים ב-`lib/forms/definitions.ts` תחת `template.placements`
(מערכת צירים של PDF: ראשית הצירים בפינה השמאלית-תחתונה, יחידות נקודות, עמוד A4 =
595x842). כל שדה מוגדר לפי `page` (אפס-בסיס) ו-`box` - גבולות התא הריק בטופס.
הטקסט ממורכז אנכית בתוך התא ומיושר לימין עם `padding`, ואפשר להוסיף `offset`
לכיוונון עדין של x/y, ו-`lines` כדי לאפשר גלישה לשורות בתאים צרים.

להצגת הקואורדינטות של התבנית לצורך כיוונון:

```bash
# מיקומי הטקסט המודפס בטופס (רק אם לתבנית יש שכבת טקסט)
node scripts/template-coords.mjs public/templates/fire-safety.pdf 1

# גבולות הטבלאות שמצוירות כווקטורים (מהם נגזרים ה-box של כל שדה)
node scripts/template-boxes.mjs public/templates/accessibility.pdf 1

# השורות למילוי, כולל שורות שמצוירות בתווי קו תחתון: y ו-x התחלה/סוף
node scripts/template-lines.mjs public/templates/police-4-2a.pdf 4

# רינדור העמוד עם סריג קואורדינטות, לקריאה ישירה של המיקומים מהתמונה
node scripts/template-grid.mjs public/templates/accessibility.pdf 1 tmp/grid.png 3 "60,440,540,600"
```

לבדיקת התוצאה עם נתוני דוגמה: `npm run form:sample police_4_8`
(הקובץ נשמר ל-`tmp/`, וברירת המחדל היא `fire_safety_declaration`). אפשר לרנדר את
הקובץ שנוצר עם אותו סריג כדי לוודא שהערכים יושבים על השורות.

חשוב: אם מחליפים את הקובץ בגרסה אחרת של הטופס, יש לוודא שמספר העמודים ומיקומי
השדות עדיין תואמים.
